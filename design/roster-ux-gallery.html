Turn a wall of bots into a legible fleet.

The live phone shows strong bot identity but weak topology: every gateway is blended into one long list, so suffixes like “-local” are doing work the interface should do. These three directions make the machine the stable frame and the bot the expressive character inside it.

OPTION A · RECOMMENDED
Best balance

Smart Fleet

Machine accordions with useful summaries. The primary machine and any group with work, unread activity or trouble open themselves; calm secondary machines stay tucked away.

  • Preserves one-tap access to the bots people use most.
  • Explains partial outages exactly where bots disappear.
  • Supports custom sections inside each machine without mixing ownership.
  • Nested sections add hierarchy, so headers must stay visually quiet.

OPTION B · ACTION FIRST

Pulseboard

Put “what needs me?” ahead of topology. A compact live rail carries working and waiting bots; every machine can safely start collapsed because its useful state remains visible.

  • Fastest route to approvals, failures and active work.
  • Makes “all machines collapsed” viable, not merely tidy.
  • Feels alive without animating the entire roster.
  • Repeats active bots when a machine opens and consumes prime vertical space.

OPTION C · CALMEST

Machine Deck

Replace nested accordions with a selected-machine lens. A swipeable machine switcher keeps one roster in view, reducing visual complexity for small and medium fleets.

  • Cleanest bot-reading experience and strongest sense of place.
  • Removes the “collapsed by default” decision entirely.
  • Closest to the density of the current screen, so migration is gentle.
  • Cross-machine comparison and fleet-wide scanning require more switching.

DECISION GUIDE

Choose the operating model first.

Color, spacing and animation can be tuned later. The durable choice is what the home screen optimizes for: topology, urgent work, or one-machine focus.
